# SOC-automation
## Build a security lab for a fictional Finnish company, connecting vulnerability management, network monitoring, web security, incident response and machine learning into one working system.

### The business scenario and finished system

**Fictional customer: "X" Logistics Oy, a small organisation with office users, a shipment portal, a Linux application server, a database and a remote support account. Use invented names and synthetic records throughout**

**Business problem: security information is spread across logs, scans and emails. An analyst repeatedly gathers the same context, prioritises issues manually and cannot reliably prove whether a fix worked.**

**Finished outcome: one incident record connects the affected asset, raw events, detection rule, vulnerability context, threat-intelligence observations, analyst decision, response action and verification evidence.**
